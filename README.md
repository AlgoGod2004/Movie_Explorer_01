# 🎬 Movie Explorer

A responsive movie discovery web application built with **HTML, Tailwind CSS, and JavaScript**. Search for movies, explore their details, and save your favorites in one place.

## ✨ Features

* 🔍 **Movie Search** — Search for movies by title using the OMDb API.
* 🎥 **Movie Details** — View information such as release year, genre, director, cast, runtime, IMDb rating, and plot.
* ❤️ **Favorites** — Add movies to your favorites and remove them whenever you want.
* 💾 **Local Storage** — Keep your favorite movies saved in your browser.
* 📱 **Responsive Design** — Browse on desktop, tablet, or mobile.
* 🌙 **Dark UI** — A modern dark theme with violet accents.

## 🛠️ Tech Stack

* HTML5
* Tailwind CSS
* JavaScript
* OMDb API
* Browser Local Storage

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/movie-explorer.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the project

Open the project folder in VS Code.

### 3. Run the application

Open `index.html` in your browser, or use the **Live Server** extension in VS Code for a convenient local development setup.

### 4. Search for a movie

Enter a movie title in the search bar, view its details, and add it to your favorites.

## 🔑 API

This project uses the [OMDb API](https://www.omdbapi.com/) to retrieve movie information.

The application requires a valid API key. Follow the provider's terms and usage limits. Do not commit private credentials to a public repository.
